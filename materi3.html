Penerapan Determinan dan Invers Matriks

🎯 Apa yang akan dipelajari?

Menggunakan determinan dan invers untuk menyelesaikan sistem determinan matriks dalam bentuk matriks.

1. 🔎 Menulis sistem dalam bentuk matriks

Perhatikan sistem: 2x + y = 5 dan x − y = 1.

AX = B, dengan A = [ [2,1], [1,−1] ], X = [ [x], [y] ], dan B = [ [5], [1] ].

2. 🧮 Hitung determinan koefisien

det(A) = (2 × −1) − (1 × 1) = −3

Karena det(A) ≠ 0, matriks A memiliki invers.

3. ✏️ Cari invers dan solusi

A⁻¹ = −1/3 [ [−1,−1], [−1,2] ]

X = A⁻¹B = [ [2], [1] ]

Jadi, x = 2 dan y = 1.

4. ✅ Periksa jawaban

2(2) + 1 = 5 ✓

2 − 1 = 1 ✓

Kedua persamaan terpenuhi.

5. 💡 Penerapan

Metode matriks dapat dipakai untuk menyelesaikan beberapa determinan matriks secara terstruktur, misalnya menentukan jumlah dan harga beberapa barang dari informasi total belanja.

Langkah penyelesaian:

Bentuk AX = B → hitung det(A) → pastikan det(A) ≠ 0 → hitung X = A⁻¹B → periksa solusi
